# 通讯接入说明（唯一协议文档）

> 本项目全部硬件通讯的**寄存器映射 / 换算 / 坑点 / 排障**汇总。按设备分节，改动协议时同步更新本文件。
> 内容来自原独立测试工程（`ModbusRtuBarometerTest` / `ModbusTcpIoControllerTest` / `ModbusTCPFanControllerTest` /
> `SerialScannerTest`，已删除）的**实测结果**，并已合并进主程序 `AgingTestSystem`。
> 测试入口：主程序"关于"菜单 → **通讯测试**（IO 耦合器）/ **送风机测试**。

## 1. 整体链路

1. 上位机按 `CollectInterval`（默认 1s）轮询 72 台气压表压力（RTU）；IO 耦合器 DI/DO 随采集轮询；送风机独立 2s 轮询。
2. 软件用 `AlarmPressureThresholdKPa`（默认 -95kPa）判报警。
3. 报警**进入边沿**触发一次联动：关该台真空电磁阀 + 断载台上电 + 标故障（`DeviceManager.HandleAlarm`）。
4. 老化测试业务：启动运行（开阀+上电+送风机定值启动）→ 真空确认 → 老化计时 → 到时/停止/急停。
5. 编排核心：`DeviceManager.cs`。

## 2. 气压表（Modbus RTU）

### 2.1 协议要点
- 一主多从：主站=上位机，72 台气压表=从站，**slaveId = deviceId（1~72）**。
- RTU 帧带 CRC；`SerialPort`/NModbus 主站**不支持并发**，生产实现用 `_syncRoot` 锁串行化（`ModbusRtuBarometerReader.cs:158`）。

### 2.2 寄存器（实测定论）

| 寄存器 | 类型 | 功能码 | 含义 |
| :--- | :--- | :--- | :--- |
| `0x0001` | Input Register | 0x04 | 压力原始值（**按有符号 short** 解释，支持负压） |
| `0x0002` | Input Register | 0x04 | 小数位数（0~4；**实测 47/72 台返回 0 不可靠**，生产统一用配置 `BarometerDefaultDecimalPlaces`=1） |
| `0x0010` | Holding Register | 0x06 | 设备阈值（写气压表内部硬件报警点） |

### 2.3 换算
- **压力**：`(short)raw / 10^小数位`（kPa）。示例：0x0001=0xFFCE → -50，小数位 1 → -5.0。**必须显式 (short) 强转**，否则 0xFFFE 被当 65534。
- **阈值**：`寄存器值 = (ushort)round(阈值浮点 × 10^小数位)`；负值按补码回绕（设备按有符号解释）。示例：-95.0、小数位 1 → 0xFC5A。

### 2.4 设备阈值写入（V1.15）
- 入口：`DeviceManager.SetBarometerThreshold(台号, 值)` 单台 / `SetAllBarometerThresholds(值)` 批量（返回失败名单，逐台失败不中断）。
- ⚠️ 单位是**设备单位**（与压力读数同单位同小数位），**不是** -95kPa 软件报警阈值；按说明书确认后再写。
- 批量写 72 台较慢，应在后台线程执行；写超时通常=该台掉线/损坏（先扫描定位）。

### 2.5 排障速查

| 现象 | 排查方向 |
| :--- | :--- |
| 未找到 CH340 | USB 未插/驱动未装（VID_1A86/PID_7523 才认） |
| Access denied | 串口被其它软件占用 |
| 读失败/重试仍失败 | 从站地址错、波特率不符、A/B 反了、共地缺失 |
| 数值巨大正数 | 没做 (short) 强转，或小数位/缩放配错 |
| 批量写某台一直超时 | **该台设备问题**（掉线/断电/地址拨错/损坏）；扫描 `Logs\BarometerScan_*.csv` 定位，多扫几遍区分"永久离线"vs"间歇掉线" |

## 3. IO 耦合器（GX-CL140 Modbus TCP）

### 3.1 硬件要点
- **SP 与 FP 都要供 24V**（SP=耦合器本体，FP=IO 模块回路；FP 断则 AL 红灯闪）。
- PC 网卡与耦合器同网段；网线插紧（**ST 闪绿但不通 = 接触不良**）。
- 指示灯：SP/SYS/AL/ST 绿常亮为正常；SYS 红闪=等网络；长按复位键>6s 恢复出厂。
- 现场规模 80DI/160DO，业务用 72DI/144DO（多出的 8DI+16DO 预留）。

### 3.2 寄存器 ↔ 通道（bit0=第1路，bit15=第16路）

| 类型 | 起始地址 | 功能码 | 说明 |
| :--- | :--- | :--- | :--- |
| DI 输入 | 0x1000 | 0x04 | 0x1000~0x1004 = DI 1~80（对应 X000~X107；65~72 气压表，73~80 预留） |
| DO 输出 | 0x2000 | 读 0x03 / 写 0x06 | 0x2000~0x2009 = DO 1~160 |

**DO 详细分布**（⚠️ 0x2004~0x2008 低/高字节被不同业务共用，**单点写必须读-改-写**）：

| 寄存器 | 低字节(bit0~7) | 高字节(bit8~15) | 业务 |
| :--- | :--- | :--- | :--- |
| 0x2000~0x2003 | — | — | 真空电磁阀 1~64（Y000~Y107） |
| 0x2004 | 电磁阀 65~72（Y100~Y107） | **载台上电 1~8（Y110~Y117）** | 混合 |
| 0x2005 | 载台上电 9~16（Y120~Y127） | 载台上电 17~24（Y130~Y137） | 载台上电 |
| 0x2006 | 25~32（Y140~Y147） | 33~40（Y150~Y157） | 载台上电 |
| 0x2007 | 41~48（Y160~Y167） | 49~56（Y170~Y177） | 载台上电 |
| 0x2008 | 57~64（Y200~Y207） | 65~72（Y210~Y217） | 载台上电 |
| 0x2009 | — | — | 预留（备用通道映射目标，DO 145~160） |

**载台上电位值规律**：偶数排=低字节从 `0x0001` 左移；奇数排=高字节从 `0x0100` 左移。例：Y110=0x2004 的 bit8=`0x0100`；Y110+Y111 同开=`0x0300`。

### 3.3 业务设备 ↔ IO（IO分配表.xlsx）

| 业务设备 | 电气 | 地址 | 通道 |
| :--- | :--- | :--- | :--- |
| 真空负压表 | NPN(漏型) | X000~X107 | DI 输入（报警硬件触点→DI，只读显示，**不参与**报警联动） |
| 真空电磁阀 | PNP(源型) | Y000~Y107 | DO 输出（控制负压） |
| 继电器(载台上电) | PNP(源型) | Y110~Y217 | DO 输出（载台 9×8 上电） |

- 八进制编址：X007 后 X010、X077 后 X100、Y107 后 Y110。第 n 点 = `X/Y + 八进制(n-1)`。
- 内部连续编号（IoMapBuilder）：输入 1~TotalInputs(80)；真空阀 = TotalInputs+deviceId；载台电 = TotalInputs+TotalBarometers+deviceId。
- NPN 低有效：触点闭合读 0 还是 1 取决于线制与 `InvertInputs`，需现场实测。

### 3.4 坑点
1. **读保持寄存器返回负值（EasyModbus 特有）**：值 ≥0x8000 被符号扩展成 int 负数，必须 `& 0xFFFF`；NModbus 返回 ushort[] 无此问题。
2. **写单点 DO 必须读-改-写**（读回→只改目标 bit→写回）；0x2004~0x2008 全部被共用，整字直写会误伤其它通道。
3. **0x2004 低字节属于电磁阀**：载台上电"全关"只清高字节、保留低字节，否则把电磁阀 65~72 一起关掉。
4. **备用通道映射**：DQ 通道烧毁时把源通道改写备用（`IoBackupChannelMappingEnabled` + `IoBackupChannelMappings`，
   格式 `源寄存器@源通道->目标寄存器@目标通道;...`，寄存器与通道均为十六进制（通道 0x00~0x1F，0x00=第 1 路），
   与设置界面显示完全一致（所见即所得）；程序内部自动把十六进制通道转成 0~31 十进制位号运算。
   写/读 DO 自动重定向，业务侧不变；通讯测试窗体读同一配置便于现场验证。

### 3.5 排障速查

| 现象 | 排查方向 |
| :--- | :--- |
| SP 不亮 | 24V 未接/正负反 |
| SYS 红 | 网络未通/IP 不同网段；长按复位>6s 恢复出厂 |
| AL 红闪 | FP 电源未接 / IO 模块未插牢 |
| ST 闪绿不通 | 网线接触不良/不在同网段 |
| 写返回 0x80 错误码 | 地址/长度超限、模块不支持 |

## 4. 送风机（Modbus TCP 端口 50000）

### 4.1 寄存器（实测，建议一次读 6 个 0x0000~0x0005）

| 寄存器 | 功能 | 读/写 | 说明 |
| :--- | :--- | :--- | :--- |
| 0x0000 | 组合状态 | 只读 | 未使用（忽略） |
| 0x0001 | 控制/状态 | 读写 | 读：0x0000=程式停止/0x0001=程式启动/0x0002=定值停止/0x0003=定值启动；写：0x0003=定值启动、0x0002=停止 |
| 0x0002 | 当前温度 | 只读 | 值/100 = °C |
| 0x0003 | 当前湿度 | 只读 | 值/100 = %RH |
| 0x0004 | 温度设定值 | 只读 | 值/100 = °C |
| 0x0005 | 湿度设定值 | 只读 | 值/100 = %RH |

### 4.2 状态枚举与中文显示
`FanRunState`：0x0000=程式停止 / 0x0001=程式启动 / 0x0002=定值停止 / 0x0003=定值启动；`Unknown(-1)`=读失败哨兵。
**坑点**：枚举必须 4 值全定义 + UI 显式 switch 映射中文（`GetStateText`），未知值兜底 `未知(0xXXXX)`，否则程式模式回 0/1 会显示裸数字。

### 4.3 生命周期与 IP 识别
- 72 台共用：有任一台测试→保持运行；全部停止→才停机。`DeviceManager.UpdateFanLifecycle`（只下发一次命令）。
- **IP 自动识别**（`FanAutoDetectEnabled` + `FanIpCandidates`，配几个识别几个）：连接顺序 =
  `FanLastIp.cache`（上次成功，工控机记忆）→ FanIpAddress → FanIpCandidates；换地址自动找到并更新缓存。
- 超时：`FanTimeoutMs`（默认 3000）兼作**连接超时**（自实现 Task.WhenAny，避免 IP 错时等 20s 假死）。
- 通讯间隔建议 ≥500ms；断线后台静默持续重连（10s 节流），只在连上/断开边沿提示一次。

### 4.4 排障
| 现象 | 排查方向 |
| :--- | :--- |
| 连不上 | FanEnabled=true、IP/端口(50000)、候选 IP 列表、网线 |
| 状态显示裸数字 | 状态枚举未 4 值/未 switch 中文 |

## 5. 扫码枪（Honeywell Xenon 1902 虚拟串口）

- **通讯参数**：115200 / 8 / None / 1，ASCII 文本流，按换行符切条码（兼容 CR/LF/CRLF）。
- **串口识别**：WMI 查询 `Win32_PnPEntity` 中名称含 `ScannerDeviceKeyword`（默认 "Xenon 1902"）的 COM 口；
  设备需先设置为**虚拟串口模式**（扫对应配置码）。
- **断连心跳（V1.16.3+）**：重连定时器每次 Tick 重新跑 WMI 动态搜索确认设备是否真在（拔 USB 后 PnP 节点消失→判定断连），
  比注册表残留/ReadExisting 可靠；WMI 查询失败退 I/O 探测兜底。
- **⚠️ 必须在 UI 线程启动（V1.23 修复）**：`ScannerService.Start()` 内部会创建 `System.Windows.Forms.Timer`
  （重连/心跳）与 `DeviceChangeWindow`（`NativeWindow`，监听 `WM_DEVICECHANGE` 热插拔），两者都依赖 UI 消息泵；
  若在 `Task.Run` 等后台线程调用，定时器不触发、热插拔收不到消息，扫码枪拔插后无法自动重连。
- **排障**：找不到端口→确认虚拟串口模式；Access denied→端口被占用；乱码→确认 ASCII 输出。

## 6. 推荐通线验证顺序

1. 先只验证 TCP：**通讯测试窗体**（IO 耦合器页）对 GX-CL140 连接/读 DI/写 DO。
2. 再验证串口 RTU：**公共参数窗口**逐个写/读气压表阈值，确认单位与小数位。
3. 用**送风机测试窗体**验证送风机：定值启停、读温湿度。
4. 最后联动：`UseMockCommunication=false`，观察 UI 的 IO 框与实际 IO 一致。
5. 触发报警：人为制造真空不足，确认**只在报警进入时**下发一次关阀/断电。
